## 一、环境准备

### 1.1 必装软件清单

| 软件 | 版本要求 | 下载地址 | 用途 |
|------|----------|----------|------|
| JDK | 11 或以上 | https://adoptium.net/ | 后端运行环境 |
| Maven | 3.6+ | https://maven.apache.org/download.cgi | 后端构建工具 |
| MySQL | 8.0+ | https://dev.mysql.com/downloads/mysql/ | 数据库 |
| Node.js | 18+ | https://nodejs.org/ | 前端运行环境 |
| 微信开发者工具 | 最新版 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html | 小程序开发 |

### 1.2 验证软件安装

打开命令行（Windows 按 `Win+R` 输入 `cmd`），依次执行以下命令验证：

```bash
# 验证 Java
java -version
# 应显示: java version "11.x.x" 或更高

# 验证 Maven
mvn -version
# 应显示: Apache Maven 3.6.x 或更高

# 验证 Node.js
node -v
# 应显示: v18.x.x 或更高

# 验证 npm（随 Node.js 安装）
npm -v
# 应显示: 9.x.x 或更高
```

### 1.3 配置环境变量（如果命令无法识别）

**Windows 系统：**

1. 右键「此电脑」→「属性」→「高级系统设置」→「环境变量」
2. 在「系统变量」中添加：
   - `JAVA_HOME` = `C:\Program Files\Java\jdk-11`（你的JDK安装路径）
   - `MAVEN_HOME` = `C:\Program Files\Apache\maven`（你的Maven安装路径）
3. 编辑 `Path` 变量，添加：
   - `%JAVA_HOME%\bin`
   - `%MAVEN_HOME%\bin`

## 二、数据库配置

### 2.1 安装并启动 MySQL

1. 安装 MySQL 8.0，记住设置的 root 密码
2. 启动 MySQL 服务：
   - Windows: 打开「服务」→ 找到 MySQL → 右键「启动」
   - 或命令行执行: `net start mysql80`

### 2.2 导入数据库脚本

**方法一：命令行导入**

```bash
# 进入项目的数据库脚本目录
cd parking-system/backend/src/main/resources

# 执行 SQL 脚本（替换 your_password 为你的 MySQL root 密码）
mysql -uroot -pyour_password < full_schema.sql
```

**方法二：MySQL Workbench / Navicat 导入**

1. 打开工具，连接到 MySQL
2. 新建查询，打开 `full_schema.sql` 文件
3. 执行全部脚本

### 2.3 验证数据库

```bash
# 登录 MySQL
mysql -uroot -p

# 查看数据库
SHOW DATABASES;

# 应看到 parking_system 数据库

# 切换数据库
USE parking_system;

# 查看表
SHOW TABLES;

# 应看到 14 张表
```

### 2.4 修改后端数据库配置

编辑 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/parking_system?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true&useAffectedRows=true
    username: root
    password: "你的MySQL密码"  # 修改这里
```

## 三、后端启动

### 3.1 进入后端目录

```bash
cd parking-system/backend
```

### 3.2 安装依赖并编译

```bash
# 清理并编译（首次运行或代码变更后执行）
mvn clean package -DskipTests
```

> 首次运行会下载依赖，可能需要 5-10 分钟，请耐心等待

### 3.3 启动后端服务

**方法一：使用 Maven 启动（开发推荐）**

```bash
mvn spring-boot:run
```

**方法二：运行 JAR 包**

```bash
java -jar target/parking-system-1.0.0.jar
```

### 3.4 验证后端启动成功

看到以下日志表示启动成功：

```
Started ParkingSystemApplication in X.XXX seconds
```

**测试接口：**

- 浏览器访问: http://localhost:8080/api/swagger-ui/
- 应显示 Swagger API 文档页面

**默认账号：**

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | admin | 123456 |
| 普通用户 | user | 123456 |

## 四、前端启动

### 4.1 新开一个命令行窗口

> 保持后端服务运行，新开一个命令行窗口

### 4.2 进入前端目录

```bash
cd parking-system/frontend
```

### 4.3 安装依赖

```bash
npm install
```

> 首次运行会下载依赖，可能需要 2-5 分钟

### 4.4 启动前端服务

```bash
npm run dev
```

### 4.5 访问前端页面

启动成功后，命令行会显示：

```
  VITE v7.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

浏览器访问: http://localhost:5173/

### 4.6 登录系统

使用后端默认账号登录：
- 管理员: `admin` / `123456`
- 普通用户: `user` / `123456`

## 五、微信小程序启动（可选）

### 5.1 打开微信开发者工具

1. 启动微信开发者工具
2. 使用微信扫码登录

### 5.2 导入项目

1. 点击「导入项目」或「+」
2. 选择项目目录: `parking-system/miniprogram`
3. AppID: 点击「测试号」使用测试号（或填写你的小程序AppID）
4. 点击「导入」

### 5.3 修改 API 地址

编辑 `miniprogram/utils/api.js`（如果存在）或相关配置文件，将 API 地址改为：

```javascript
const BASE_URL = 'http://localhost:8080/api';
```

> 注意：小程序真机调试需要使用内网穿透工具，开发工具中可勾选「不校验合法域名」

### 5.4 运行小程序

1. 点击「编译」按钮
2. 模拟器中会显示小程序界面
3. 可选择「预览」生成二维码，手机微信扫码体验

## 六、常见问题

### Q1: 后端启动报错 "Communications link failure"

**原因：** MySQL 未启动或连接配置错误

**解决：**
1. 确认 MySQL 服务已启动
2. 检查 `application.yml` 中的数据库密码是否正确
3. 确认数据库 `parking_system` 已创建

### Q2: 后端启动报错 "端口 8080 被占用"

**解决：**

```bash
# Windows 查看占用端口的进程
netstat -ano | findstr :8080

# 结束进程（PID 为上一步查到的进程ID）
taskkill /PID 进程ID /F
```

或修改 `application.yml` 中的端口：
```yaml
server:
  port: 8081  # 改为其他端口
```

### Q3: 前端 npm install 报错

**解决：**
```bash
# 清除缓存
npm cache clean --force

# 删除 node_modules 重新安装
rmdir /s /q node_modules
del package-lock.json
npm install
```

### Q4: 前端页面空白或接口报错

**原因：** 后端未启动或跨域问题

**解决：**
1. 确认后端已启动并运行在 8080 端口
2. 检查浏览器控制台（F12）的错误信息
3. 确认后端 `application.yml` 中 `context-path: /api`

### Q5: 登录提示密码错误

**原因：** 数据库未正确初始化

**解决：**
1. 重新执行 `full_schema.sql` 脚本
2. 确认数据库中有默认用户数据：
```sql
SELECT * FROM user;
```

### Q6: Maven 下载依赖很慢

**解决：** 配置国内镜像源

编辑 Maven 的 `settings.xml`（位于 Maven 安装目录的 `conf` 文件夹）：

```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <name>Aliyun Maven</name>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### Q7: 小程序无法连接后端

**解决：**
1. 开发工具中勾选「详情」→「本地设置」→「不校验合法域名、web-view...」
2. 确认后端 API 地址正确
3. 真机调试需使用内网穿透（如 ngrok、cpolar）

## 快速启动命令汇总

```bash
# ========== 数据库 ==========
mysql -uroot -p < backend/src/main/resources/full_schema.sql

# ========== 前端（新窗口）==========

npm install
npm run dev
```
